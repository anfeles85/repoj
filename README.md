# Repoj

Aplicativo para el análisis del reporte de juicios evaluativos de SofiaPlus.

## 🚀 Características

- **Carga de archivos**: Sube reportes de juicios evaluativos en formato CSV.
- **Visualización interactiva**: Explora los datos a través de tablas interactivas.
- **Métricas en tiempo real**: Obtén estadísticas instantáneas sobre el rendimiento académico.
- **Análisis por corte**: Filtra y analiza el rendimiento por fecha de corte.
- **Exportación de datos**: Descarga los resultados en formato Excel.

## 🛠️ Tecnologías

- **Frontend**: Vue.js 3
- **Ecosistema de desarrollo**: Vite
- **Componentes**: Vuetify 3
- **Visualización**: ECharts

## 🏁 Instalación

1. Clona el repositorio:
   ```bash
   git clone <url-del-repositorio>
   cd repoj
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

3. Ejecuta la aplicación en modo desarrollo:
   ```bash
   npm run dev
   ```
   La aplicación estará disponible en `http://localhost:5173`.

## 📦 Build

Para generar una versión de producción:

```bash
npm run build
```

## ⏭️ Despliegue (Preview)

Para previsualizar la versión de producción:

```bash
npm run preview
```
