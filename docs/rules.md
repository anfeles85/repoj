# REGLAS PARA EL DESARROLLO DE REPOJ

Todo cambio o adición a la aplicación debe realizarse siguiendo las reglas establecidas en este archivo.

1. Usar Vue 3.
2. Usar Composition API.
3. Usar `<script setup lang="ts">`.
4. Usar TypeScript.
5. Evitar `any`.
6. Separar vistas de componentes.
7. Separar servicios API de las vistas.
8. Utilizar interfaces TypeScript para las respuestas de API.
9. Utilizar Vue Router.
10. Utilizar Pinia cuando exista estado compartido.
11. Utilizar variables de entorno para URLs.
12. No duplicar código.
13. Crear componentes reutilizables.
14. Manejar estados `loading`, `success` y `error`.
15. Implementar manejo consistente de errores HTTP.
16. Utilizar lazy loading para las vistas.
17. Mantener nombres de archivos y variables claros.
18. No utilizar código de Vue 2.
19. No colocar llamadas Axios directamente en múltiples componentes.
20. Mantener una arquitectura preparada para crecer.
21. La base de datos a usar siempre será SUPABASE, no guardar datos en localStorage ni cargar mock desde storage
22. Para toda la plantilla HTML, usa el color #39A900 como color institucional.
