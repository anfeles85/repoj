# REQ002
## Requerimientos fase 2

En repoj existes Grupos. Estos poseen un id, un número único, un programa de formación, fecha de inicio y fecha de fin, una jornada y un estado. Los grupos contienen aprendices SENA, pero en esta fase no vamos a crear nada que tenga que ver con aprendices.

En supabase ya se encuentra creada la tabla groups para el almacenamiento de esta información. El código SQL de la tabla es:

```sql
create table public.groups (
  id bigint generated by default as identity not null,
  number bigint null,
  program character varying null,
  shift public.grupo_shift null,
  initial_date date null,
  final_date date null,
  status public.grupo_status null,
  created_at timestamp with time zone not null default now(),
  constraint grupo_pkey primary key (id),
  constraint grupo_number_key unique (number)
) TABLESPACE pg_default;
```

Los nombres de las columnas están en inglés al igual que los tipos de datos. En la app se deberán usar estos mismos nombres en el código fuente pero en español en las interfaces con el usuario.

El sistema debe tener:
- un sistema de gestión de grupos que permita:
    - crear grupos
    - editar grupos
    - eliminar grupos    
    - listar grupos

Construye estos requerimientos teniendo en cuenta la arquitectura creada en el proyecto cumpliendo siempre con lo estipulado en el archivo docs/rules.md. También mantiene el mismo estilo de UI creado en el módulo de gestión de usuarios. No revisites el archivo docs/req001.md.
