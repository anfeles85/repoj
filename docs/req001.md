# REQ001
## Requerimientos fase 1

En repoj se tendrán los siguientes roles de usuario:

- **ADMINISTRADOR**: tendrá acceso a todos los módulos del sistema. Es el único que puede crear usuarios instructores y coordinadores. El sistema no debe permitir crear nuevos administradores.
- **INSTRUCTOR**: se registra en el sistema a través de un formulario con sus datos. Puede crear grupos, subir archivos y ver todos los informes de las fichas que él cree.
- **COORDINADOR**: podrá consultar los grupos creados por todos los instructores y ver sus informes.

Datos de los usuarios: id, nombre completo, correo, rol(admin, instructor, coordinador), contraseña (encriptada con bcrypt), estado(activo, inactivo).

El sistema debe tener:
- un formulario de registro únicamente para usuarios instructores
- un formulario de inicio de sesión
- un formulario de recuperación de contraseña
- un sistema de gestión de usuarios que permita:
    - crear usuarios instructores
    - editar usuarios instructores
    - eliminar usuarios instructores
    - crear usuarios coordinadores
    - editar usuarios coordinadores
    - eliminar usuarios coordinadores
    - activar/desactivar usuarios de cualquier rol, a excepción del administrador

Construye estos requerimientos teniendo en cuenta la arquitectura creada en el proyecto cumpliendo siempre con lo estipulado en el archivo docs/rules.md
