Para la vista te sugiero antes del dashboard coloque un filtro de grupos, para que el usuario seleccione primero el grupo el cual quiere analizar.

Luego de seleccionar el grupo, mostrar lo siguiente:

## Distribución de juicios evaluativos

Aqui colocar gráfica circular de aprobados y por evaluar (se tienen en cuenta los juicios evaluativos de aprendices EN FORMACION, no los otros estados)

- Mostrar, dada una competencia seleccionada y su respectivos resultados de aprendizaje, la cantidad de aprendices POR EVALUAR y APROBADO

## Evolución temporal

El archivo tiene fecha y hora del juicio evaluativo, esto servirá para mostrar en una gráfica temporal la cantidad de juicios evaluativos evaluados por cada mes.

Pero además podemos clasificar a los aprendices:
| Nivel      | Porcentaje aprobado |
| ---------- | ------------------: |
| 🟢 Alto    |              ≥ 90 % |
| 🟡 Medio   |           70 - 89 % |
| 🟠 Bajo    |           50 - 69 % |
| 🔴 Crítico |              < 50 % |

Importante: estos rangos serían reglas de visualización del dashboard, no una conclusión pedagógica sobre el desempeño del aprendiz. Todos los aprendices deben tener su nivel clasificado de esta manera, sin importar el estado en el que se encuentren.

### Matriz de calor de aprendices

Esto permite encontrar patrones de rendimiento entre los aprendices. Para ello coloca en filas los aprendices y en columnas las competencias. En cada celda se muestra verde para APROBADO, rojo para POR EVALUAR (tener en cuenta que una competencia se considera totalmmente Evaluada si todos sus resultados de aprendizaje están APROBADOS)

Ejemplo:
             C1   C2   C3   C4   C5   C6 ...
Aprendiz 01  🟢   🟢   🟢   🟢   🟢   🟢
Aprendiz 02  🟢   🟢   🔴   🟢   🟡   🟢
Aprendiz 03  🔴   🔴   🔴   🟡   🟢   🔴
...


Importante: Para toda la analítica ten en cuenta siempre que una competencia se considera totalmmente Evaluada si todos sus resultados de aprendizaje están APROBADOS.
