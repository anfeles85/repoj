# REQ006
## Requerimientos fase 6

En repoj se requiere que el módulo de Olvidó su Contraseña, se realice con el envío de correo electrónico de la siguiente manera:
 
1. El usuario da clic en la opcion Olvidó su contraseña
2. El usuario ingresa su correo electrónico de usuario registrado
3. El sistema le envía un correo electrónico, notificándole que se ha solicitado un cambio de contraseña. Este correo tiene un botón y/o link que lo lleva a una página para realizar el cambio de contraseña.
4. El usuario da clic en el botón y/o link, y lo lleva a una página para realizar el cambio de contraseña.
5. El usuario ingresa su nueva contraseña y confirma la contraseña.
6. El usuario da clic en el botón Guardar, y el sistema le envía un correo electrónico, notificándole que su contraseña ha sido cambiada.
7. El usuario puede iniciar sesión con su nueva contraseña.

Se debe validar que el link generado sea para uso único del usuario que lo generó. Y que el enlace expire después de 1 hora. En cualquier de los casos, si el usuario intenta acceder al link después de la hora, se debe notificar que el link ha expirado. Y si el usuario intenta acceder al link después de que se ha utilizado, se debe notificar que el link ha sido utilizado.

Para el envío de correos ya se establecieron las siguientes variables de entorno en el archivo .env
- SMTP_HOST
- SMTP_PORT
- SMTP_SECURE
- SMTP_USER
- SMTP_PASS
- SMTP_FROM
